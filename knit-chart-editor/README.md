# 织图 · 离线针法图编辑器

面向手工编织设计师的**纯离线**针法图（chart）编辑器。打开即进入可编辑网格，所有数据保存在浏览器 IndexedDB 中，无需网络与账号。

## 运行

```bash
npm install
npm run dev        # 开发
npm run build      # 类型检查 + 生产构建（dist/ 可离线部署）
npm test           # 逻辑单元测试（vitest）
```

## 功能

### 网格编辑（React + Konva）
- 打开即进入可编辑网格；行 1 在织物底部，自下而上编号
- 框选、全选（Ctrl+A）、复制/剪切/粘贴（Ctrl+C/X/V）、删除（Delete）
- 针法 / 颜色 / 橡皮三种画笔，拖动连续绘制
- **分组撤销**：一次笔画、一次粘贴、一次镜像、一次母版应用各占一个撤销步（Ctrl+Z / Ctrl+Y）
- 大网格虚拟化渲染 + 自定义滚动条；**选区保存在模型坐标中，滚动、缩放、自动滚屏都不会丢失选区**
- Ctrl+滚轮缩放，拖动到边缘自动滚动

### 针数计算（不只是涂色）
- 每个针法有「消耗针数 → 产生针数」（见 `src/data/symbols.ts`）：并针 2→1、空针 0→1、无针目 0→0……
- 逐行推算行首/行末针数（第 1 行行首 = 起针数），**行首实有针数与本行所需针数不符的行**会在左侧行号栏标红，并在「针数校验」面板列出：第几行、需要几针、实际几针、差几针，点击可跳转定位

### 镜像与倾斜针法
- 左右镜像选区时自动互换倾斜针法：K2tog↔SSK、K3tog↔SSSK、M1L↔M1R；上下镜像只翻转行序

### 花样母版与循环展开
- 母版在独立编辑器中绘制（支持透明格）
- 「放置」按横向×纵向循环展开到主图，**每个展开格保留母版引用**（紫色角标）
- 编辑母版保存后，先弹出**影响预览**（涉及几处引用、多少格子，主图橙色高亮），确认「应用」才生效；用户手工改过的格子已脱离引用，不会被覆盖

### 分页打印
- A4 纵向自动分页（40 列 × 50 行/页），页眉标注行/列范围与页码，末页为针法+颜色图例与针数校验摘要
- 打印预览确认后调用系统打印

### 持久化
- Dexie 写入 IndexedDB，编辑后 400ms 防抖自动保存，关闭页面前强制落盘
- 内置两套样例工程（首次启动自动创建）：
  - **样例A · 镂空围巾（针数正确）**：含母版循环展开实例，全部行针数匹配
  - **样例B · 针数冲突（教学示例）**：第 6/10/11 行故意制造行首针数不匹配，并演示用「无针目」「空针」修复的正确做法

## 目录结构

```
src/
  types.ts            数据模型（工程/单元格/母版/实例/补丁）
  data/symbols.ts     本地针法与颜色图例（含 consumes/produces/mirrorOf）
  data/samples.ts     两套样例工程与母版
  lib/stitchMath.ts   逐行针数推算与冲突检测
  lib/ops.ts          选区/复制/粘贴/镜像/删除（纯函数，产出补丁）
  lib/master.ts       母版展开、影响预览、应用（纯函数）
  lib/glyphs.ts       针法矢量字形（Konva 与打印 SVG 共用）
  state/store.ts      zustand 状态、分组撤销、防抖保存
  db/db.ts            Dexie / IndexedDB
  components/         GridCanvas(Konva) / 面板 / 母版编辑器 / 打印视图
```

## 快捷键

| 键 | 功能 |
| --- | --- |
| Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+C / X / V | 复制 / 剪切 / 粘贴 |
| Ctrl+A | 全选 |
| Delete / Backspace | 删除选区 |
| Ctrl+P | 打印预览 |
| Esc | 取消放置 / 关闭预览 / 清除选区 |
| Ctrl+滚轮 | 缩放 |
